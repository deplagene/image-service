# Image Processing Service

Сервис для обработки изображений с использованием микросервисной архитектуры. Позволяет загружать изображения, применять к ним фильтры (черно-белый, резкость) и получать обработанные результаты.

## Архитектура

Проект состоит из следующих компонентов:

- **API Gateway** (`cmd/api`) - основной сервер, обрабатывающий HTTP-запросы
- **Image Service** (`services/image`) - сервис для обработки изображений
- **S3 Storage** (`services/s3`) - интеграция с MinIO для хранения изображений
- **Message Broker** (`services/rabbitmq`) - RabbitMQ для асинхронной обработки
- **Frontend** (`frontend`) - веб-интерфейс для загрузки и просмотра изображений

## Технологии

- **Backend**:
  - Go 1.24
  - PostgreSQL
  - MinIO (S3-совместимое хранилище)
  - RabbitMQ
  - Docker

- **Frontend**:
  - HTML5
  - CSS3 (Tailwind CSS)
  - JavaScript (ES6+)

## Требования

- Go 1.24 или выше
- Docker и Docker Compose
- PostgreSQL
- MinIO
- RabbitMQ

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd teach-stack
```

2. Настройте переменные окружения:
```bash
cp .env.example .env
# Отредактируйте .env файл под ваши настройки
```

3. Запустите сервисы через Docker Compose:
```bash
docker-compose up -d
```

4. Запустите бэкенд:
```bash
go run cmd/main.go
```

5. Запустите фронтенд:
```bash
cd frontend
go run server.go
```

## Использование

1. Откройте веб-интерфейс по адресу `http://localhost:3000`
2. Загрузите изображение через drag-and-drop или кнопку выбора файла
3. Дождитесь обработки изображения
4. Скачайте или просмотрите обработанное изображение

## Доступные фильтры

- Черно-белый (bw)
- Повышение резкости (sharpen)

## API Endpoints

- `POST /upload` - загрузка изображения
- `GET /images/{id}` - получение обработанного изображения

## Мониторинг

Сервис интегрирован с Prometheus для мониторинга метрик:
- Количество загруженных изображений
- Время обработки
- Статусы обработки

## Логирование

Используется структурированное логирование с помощью slog:
- Уровни: DEBUG, INFO, WARN, ERROR
- Формат: JSON
- Контекстная информация
